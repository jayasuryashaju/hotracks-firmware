Install Rack Controller Firmware

Flashes the HotRacks controller firmware straight from your browser onto an ESP32-C3 (Super Mini) board over USB — no Arduino IDE, no drivers beyond the board's own USB-serial chip.

  1. Browser: use Chrome or Edge on a desktop/laptop (Web Serial isn't supported on mobile or Firefox/Safari).
  2. Wiring: have your WS2812B strip's data line on the configured GPIO pin, common ground with the board, and a separate 5V supply for the strip.
  3. Plug the ESP32-C3 in over USB, click install below, and pick its serial port when your browser prompts you.
  4. After it reboots, connect to its HotRacks-Setup Wi-Fi network to finish provisioning (see the main firmware README).
Your browser doesn't support Web Serial. Open this page in Chrome or Edge on a desktop computer instead. This page needs to be served over HTTPS (or localhost) to flash a device — you're seeing this because it isn't right now.
